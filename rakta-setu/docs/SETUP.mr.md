# रक्त-सेतू — सेटअप मार्गदर्शक

हे मार्गदर्शक प्रयोगशाळेतील संगणकावर रक्त-सेतू सुरू करण्यासाठी आहे.
तांत्रिक माहिती नसली तरी टप्प्याटप्प्याने करता येईल.

---

## टप्पा १ — Node.js बसवा

१. [nodejs.org](https://nodejs.org) वर जा.
२. **LTS** आवृत्ती डाउनलोड करा (आवृत्ती २० किंवा त्यापुढची).
३. डाउनलोड झालेली फाइल उघडून Next-Next करत बसवा.
४. तपासण्यासाठी Command Prompt उघडा आणि टाइप करा:

```bash
node --version
```

`v20.…` किंवा त्यापुढचा आकडा दिसला पाहिजे.

---

## टप्पा २ — प्रकल्प उतरवून घ्या

```bash
git clone https://github.com/<तुमचं-नाव>/rakta-setu.git
cd rakta-setu
npm install
```

`npm install` ला पहिल्यांदा २–३ मिनिटं लागतात.

---

## टप्पा ३ — सेटिंग फाइल तयार करा

```bash
copy .env.example .env        # Windows
cp .env.example .env          # Mac / Linux
```

आता `.env` ही फाइल Notepad मध्ये उघडा आणि हे बदल करा:

```ini
LAB_NAME=तुमच्या प्रयोगशाळेचं नाव
LAB_PHONE=+919822012345
LAB_CITY=पुणे

# रक्त तपासणी यंत्र ज्या फोल्डरमध्ये अहवाल टाकतं तो पत्ता
# Windows मध्ये \ ऐवजी / वापरा
WATCH_DIR=C:/BloodMachine/Reports

# हे एक लांब आणि कोणालाही ओळखता येणार नाही असं वाक्य ठेवा
ADMIN_TOKEN=majhi-lab-cha-khup-lamb-ani-gupt-password-2026
```

> ⚠️ **`.env` ही फाइल कोणालाही पाठवू नका आणि GitHub वर टाकू नका.**
> तिच्यात तुमचे पासवर्ड असतात.

---

## टप्पा ४ — आधी डेमोवर चाचणी घ्या

खरे अहवाल जोडण्याआधी सगळं नीट चालतंय का ते पहा:

```bash
npm run seed
npm start
```

`npm run seed` एक लिंक आणि ४ अंकी PIN दाखवेल. ती लिंक ब्राउझरमध्ये उघडा,
PIN टाका — आणि रुग्णाला जे दिसेल तेच तुम्हाला दिसेल.

सुरुवातीला `WHATSAPP_DRIVER=console` असल्यामुळे **कोणालाही खरा संदेश जात नाही** —
संदेश फक्त स्क्रीनवर छापला जातो. चाचणीसाठी हे सुरक्षित आहे.

---

## टप्पा ५ — तुमच्या यंत्राचा अहवाल तपासा

यंत्रातून आलेली एक जुनी फाइल घ्या आणि ती नीट वाचली जाते का ते पहा.
**यात कोणालाही संदेश जात नाही:**

```bash
node scripts/ingest-file.js "C:/BloodMachine/Reports/junaa-report.pdf"
```

- सगळ्या तपासण्या दिसल्या → 👍 पुढे जा.
- काही तपासण्या सुटल्या → त्यांची नावं `src/domain/analytes.js` मधल्या
  `aliases` यादीत जोडा (यंत्र जे नाव छापतं तेच लिहा).
- `SCANNED_PDF` अशी चूक दिसली → तुमचं यंत्र फक्त स्कॅन केलेली प्रतिमा देतं.
  तुमच्या सॉफ्टवेअरमधून **CSV export** चा पर्याय शोधा — तो जास्त विश्वासार्ह आहे.

## टप्पा ६ — व्हॉट्सॲप जोडा

हा टप्पा थोडा तांत्रिक आहे. सविस्तर माहिती **[WHATSAPP.md](WHATSAPP.md)** मध्ये आहे.

जोडणी झाल्यावर तपासून पहा — **स्वतःच्याच नंबरवर** एक चाचणी संदेश पाठवा:

```bash
node scripts/send-test.js 9822012345
```

## टप्पा ७ — इंटरनेटवर उपलब्ध करा

रुग्णाच्या मोबाईलवरून लिंक उघडायची असेल, तर सर्व्हर इंटरनेटवर दिसायला हवा.
शिवाय **आवाजाने प्रश्न विचारण्यासाठी `https://` आवश्यक आहे** — साध्या `http://`
वर ब्राउझर माइक वापरू देत नाही.

सोपा मार्ग — [Cloudflare Tunnel](https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/):

```bash
cloudflared tunnel --url http://localhost:3000
```

हे एक `https://…trycloudflare.com` असा पत्ता देईल. तो `.env` मध्ये टाका:

```ini
PUBLIC_BASE_URL=https://तुमचा-पत्ता.trycloudflare.com
```

आणि सर्व्हर पुन्हा चालू करा.

## टप्पा ८ — रोजचा वापर

```bash
npm start
```

एवढंच. आता यंत्रातून अहवाल आला की तो आपोआप वाचला जातो आणि रुग्णाला
व्हॉट्सॲपवर लिंक जाते.

- **कर्मचारी कक्ष:** `http://localhost:3000/staff` — कोणाला पाठवलं, कोणी उघडलं,
  पुन्हा पाठवायचं का, हे सगळं इथे दिसतं. (`ADMIN_TOKEN` लागतो.)

### संगणक सुरू होताच आपोआप चालू करण्यासाठी

```bash
npm install -g pm2
pm2 start src/server.js --name rakta-setu
pm2 save
pm2 startup        # आणि दिसणारी आज्ञा चालवा
```

## अडचणी · Troubleshooting

| काय दिसतं | काय करावं |
|---|---|
| `फोन नंबर सापडला नाही` | अहवालात मोबाईल नंबर छापला जात नाही. यंत्राच्या सॉफ्टवेअरमध्ये तो छापायची सोय करा, किंवा `failed/` फोल्डरमधून हाताने पाठवा. |
| `SCANNED_PDF` | PDF फक्त प्रतिमा आहे. CSV export वापरा. |
| `NO_MEASUREMENTS` | तपासण्यांची नावं ओळखली गेली नाहीत. `analytes.js` मध्ये `aliases` जोडा. |
| माइकचं बटण चालत नाही | `PUBLIC_BASE_URL` `https://` असायला हवा. तसंच Chrome वापरा. |
| संदेश जात नाही | `node scripts/send-test.js <नंबर>` चालवा आणि [WHATSAPP.md](WHATSAPP.md) पहा. |
| आवाज मराठीत नाही | मोबाईलमध्ये मराठी voice pack नसेल तर हिंदी आवाज वापरला जातो. Android सेटिंग → भाषा → Text-to-speech मधून मराठी बसवा. |

## फोल्डर काय करतात

| फोल्डर | काय आहे |
|---|---|
| `inbox/` | यंत्र इथे अहवाल टाकतं (किंवा `WATCH_DIR` जिथे असेल तिथे) |
| `archive/` | यशस्वीपणे पाठवलेले अहवाल |
| `failed/` | न वाचता आलेले किंवा न पाठवता आलेले — **इथे नियमित लक्ष द्या** |
| `data/` | डेटाबेस. **याचा नियमित बॅकअप घ्या.** |

`data/`, `inbox/`, `archive/`, `failed/` आणि `.env` हे कधीही GitHub वर जात नाहीत —
`.gitignore` मध्ये तशी सोय केलेली आहे.
